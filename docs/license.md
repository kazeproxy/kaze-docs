# 授权说明

## 免费版 / 授权版

| | 免费版 | 授权版 |
| --- | :---: | :---: |
| 每节点有效用户数 | 100 | 按授权 |
| 协议 | 全部 | 按授权覆盖的协议 |
| 功能 | 全部 | 全部 |
| 节点收到的有效用户 | ≤ 300 人 | 不限 |

**不填授权就是免费版**，协议和功能都不阉割，只限每节点 100 个有效用户；面板下发给节点的有效用户名单超过 300 人时，免费版拒绝服务（日志会说明），这样的站点需要授权。

「有效用户」指有效套餐内、未到期、流量未超、未封禁的用户，以面板下发给节点的名单为准。

## 购买

授权在 Telegram 销售机器人 [@kaze_auth_bot](https://t.me/kaze_auth_bot) 里购买、续费、升级、换绑，USDT（TRC20）付款，付款后即时发放。

- **档位**：按协议数量（1 种到全部）× 人数档位（500 / 2000 / 6000 / 不限）× 期限（半年、1 年、2 年、3 年、永久）计价，机器人里选好即显示价格。
- **升级**：人数或协议不够用时在机器人里升级，按剩余时间补差价，节点自动生效。
- **售后**：问题先看[常见问题](faq.md)，解决不了用机器人主菜单的「联系客服」，或到频道 [@kaze_core](https://t.me/kaze_core) 的评论区留言。

## 购买须知

- 授权一经发放**不退款**；买错档位可以在机器人里升级补差价，不能降级。
- 授权绑定一个面板，该面板下节点数不限；首次绑定 24 小时内可免费换绑一次，之后每次换绑收手续费、每 30 天最多一次。
- 授权码仅供购买者的面板使用，不得转售；需要转给别人（换号、换人）时联系客服转让。
- 节点向授权服务器上报的只有授权码、面板域名、节点实例 ID 和用户的脱敏标识（哈希），**不含用户 IP、邮箱、流量内容**。
- 授权服务器维护或故障在 [@kaze_core](https://t.me/kaze_core) 公告；节点手上的租约可撑 7 天。

## 授权码

授权码形如 `KZ-XXXX-XXXX-XXXX`，在机器人购买后即时发放。填法：

```ini
license_key=KZ-XXXX-XXXX-XXXX
```

或存成文件：

```ini
license_file=/etc/kaze/license.txt
```

一键安装时加 `--license KZ-XXXX-XXXX-XXXX`，Docker 写在 `environment` 里。查看授权状态：

```bash
kaze license
```

## 绑定面板

授权码**不用事先填域名**：第一个用它对接的面板自动成为绑定面板，之后只有这个面板的节点能用。同一个面板下所有节点共用一个授权码，节点数量不限。

「同一个面板」按 `webapi_url` 的**主机名**判断：协议、端口、大小写、末尾斜杠都不算，三台机器只要域名一样就是同一个面板。用 IP 对接会绑到那个 IP，之后改成域名就算另一个面板。

绑定错了（比如先在测试面板试了一下），首次绑定 **24 小时内可以在机器人里免费换绑一次**；之后每次换绑收手续费，且每 30 天最多换绑一次。换绑是「解绑」：确认后旧面板的节点最晚 6 小时内失效，下一个用这个授权码对接的面板自动绑定；旧面板不能再把它绑回去。

**面板换域名也算换绑**：新域名的节点签到会得到 `LICENSE_REFUSED mismatch`。顺序是：先在机器人里「换绑」（解绑），再把每台机器 `kaze config webapi_url=https://新域名 && kaze restart`，第一台签到的就把码绑到新域名上。计划换域名时把所有机器一起改，别分几天改。

## 节点怎么校验

节点启动时向授权服务器签到一次，拿到一张 **7 天有效的租约**，之后每 6 小时续一次。续费、升级、换绑都在下一次签到时生效，**不用换码、不用重启**。

授权服务器连不上时，节点在手里的租约到期前照常运行（最长 7 天），日志里会提示 `LICENSE_SERVER_UNREACHABLE`；超过 7 天仍连不上才退回免费版。节点需要能访问 `license_server`（默认 `https://auth.kazecore.dev`，开了出站防火墙的机器要放行；一般不用改）。授权服务器维护或故障会在频道 [@kaze_core](https://t.me/kaze_core) 公告。

永久授权同样要定期签到，规则一样。

`kaze license` 看当前状态，一行：

```text
LICENSE_OK licence KZ-XXXX-****-****, up to 2000 users, until 2027-04-11 (checked in)
```

拒绝时会写原因，例如 `LICENSE_REFUSED licence KZ-XXXX-****-**** refused (mismatch): this licence is bound to panel.example.com, not this panel`。绑定的面板、到期日、人数在机器人「我的授权」里也能看到。

## 到期

到期后节点退回免费版，规则和没填授权码一样：

- 节点的有效用户 **≤ 300 人**：按用户 ID 从小到大保留前 100 人继续服务，其余暂时连不上，**不会停机**。
- 节点的有效用户 **> 300 人**：免费版拒绝服务，这个节点的用户都连不上，直到续费。

所以大站请不要让授权过期。到期前 7 天、前 1 天和到期当天，机器人会私信提醒（带「续费」按钮），节点日志也有 `LICENSE_ENDING_SOON`。在机器人里续费后，下一次签到（最长 6 小时）自动恢复；想立即恢复 `kaze restart`（启动时会签到一次）。

## 超出人数

超出授权人数时，**已经在用的用户不受影响**，只有新来的用户暂时无法连接，日志里有提示。

- 有人套餐到期或被停用，空出的名额按用户 ID 从小到大让给排队的新用户。
- 到期后又续费回来的用户，算作新来的：有空位才能接入，不会把正在用的人挤掉。
- 授权人数变少时（例如授权过期退回免费版），已在用的用户里按 ID 从小到大保留。

人数按面板下发给节点的用户计算，面板只下发有效用户，所以不会把过期、超流量、被封禁的用户算进去。

授权服务器会统计一个授权码在 24 小时内实际服务过的不同用户数（按节点上报的脱敏标识汇总，不含用户信息）。超过授权人数的 1.1 倍时日志提示 `LICENSE_OVER_LIMIT`，节点不再接纳新用户；超过 1.5 倍并持续两天，授权服务器拒绝签到。遇到这种情况请在机器人里升级人数档位。

## 日志里的授权状态

| 日志 | 含义 | 处理 |
| --- | --- | --- |
| `LICENSE_OK` | 授权正常 | — |
| `LICENSE_ENDING_SOON` | 7 天内到期 | 机器人里续费 |
| `LICENSE_OVER_LIMIT` | 24 小时内服务的用户超过授权人数的 1.1 倍，节点不再接纳新用户 | 升级人数档位 |
| `LICENSE_REFUSED` | 授权码无效（`unknown_code`）、已过期（`expired`）、绑定在别的面板（`mismatch` / `moved`）、被停用（`suspended` / `revoked`）、超出人数 1.5 倍并持续两天（`over_limit`），括号里的词会出现在日志里 | 按提示在机器人里处理 |
| `free edition ... does not cover` | 授权不含这个节点的协议，该节点按免费版（100 人）运行 | 升级授权，或换成授权覆盖的协议 |
| `this build has been modified` | 程序文件或授权被改动过 | 重新用一键脚本安装官方版本 |
| `LICENSE_SERVER_UNREACHABLE` | 连不上授权服务器，先按上次租约运行 | 检查节点出网和 DNS |
| `LICENSE_LEASE_EXPIRED` | 7 天没签到成功，退回免费版 | 同上 |
| `LICENSE_CLOCK_ROLLBACK` | 系统时间被调回，等待重新签到 | 校准系统时间 |
